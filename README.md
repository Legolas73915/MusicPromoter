# 🎵 Music Promoter v1.0

Music Promoter es una aplicación en Python diseñada para **registrar contenido musical** y **crear promociones automáticas** para distintas plataformas como YouTube, Instagram y TikTok.  
Su objetivo es ayudar a artistas independientes a difundir su música de manera sencilla y organizada.

---

## 🚀 Características principales
- Registrar canciones, videos u otros contenidos musicales.
- Visualizar el contenido registrado en la biblioteca.
- Crear promociones personalizadas para:
  - YouTube
  - Instagram
  - TikTok
- Generar hashtags automáticos según el tipo de contenido.
- Guardar y consultar todas las promociones creadas.

---

## 📂 Estructura del proyecto
- `music_promoter.py` → Archivo principal con toda la lógica del programa.
- `biblioteca` → Lista donde se almacenan los contenidos registrados.
- `promociones` → Lista donde se guardan las promociones generadas.

##📖 Ejemplo de uso
Al iniciar, verás el menú principal:
=========================
  Music Promoter v1.0
=========================

1. Registrar contenido
2. Ver contenido registrado
3. Crear promoción
4. Ver promociones
5. Salir

Registra una canción con su nombre, artista, tipo de contenido, enlace y plataforma principal.

Crea una promoción seleccionando la plataforma (YouTube, Instagram o TikTok).

El sistema generará automáticamente un texto promocional y hashtags relacionados.
